# Debug Mode

Hotkeys available when running ArkPets in debug mode.

### Prerequisites
Logging level must be set to `DEBUG` or launched with the `--debug` parameter to activate debugging routines.

### Usage
| Key | Function |
|---|---|
| <kbd>D</kbd> | Displays current frames per second (FPS) and JVM heap memory consumption. |
| <kbd>P</kbd> | Displays bounding box planes and physics collision boundaries. |
| <kbd>S</kbd> | Captures screen state. Screenshots are saved to `temp/snapshot-<TIMESTAMP>.png` inside the working directory. |
| <kbd>W</kbd> | Displays system window handle debug lists. |
